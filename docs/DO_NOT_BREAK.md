# Ne pas casser

Les changements Fintech ne doivent pas supprimer les flux existants : achat de carte, demandes, stock, impression, livraison, notifications, profils et espaces Admin Général, Chef d'agence, Designer graphique et Livreur.

La nouvelle navigation client est une couche d'entrée Fintech. `/client/cards` reste monté et accessible depuis l'onglet Cartes.
