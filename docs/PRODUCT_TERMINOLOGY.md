# Terminologie officielle Market-Cash

- **Wallet Market-Cash** : portefeuille local et compte de valeur du client.
- **Carte physique Market-Cash** : extension physique du wallet local ; ce n'est pas une carte Visa. Paiements locaux QR/NFC.
- **Visa virtuelle Market-Cash** : carte internationale exclusivement virtuelle dans l'application ; service partenaire, Coming soon tant que l'issuer n'est pas activé.
- **GMH APIs** : moteur commissionnaire/orchestrateur des API partenaires. GMH APIs n'est pas le wallet et ne détient pas la comptabilité Market-Cash.
- **e-SIM** : futur service partenaire.
- **Crypto** : futur service partenaire soumis aux intégrations et exigences de conformité applicables.
