# Client navigation acceptance

- Authenticated client resolves to `/client/home`.
- Bottom navigation contains exactly five primary destinations: Accueil, Cartes, e-SIM, Crypto, Profil.
- Header exposes Notifications and Menu.
- Menu exposes Wallet and Aide.
- Wallet exposes send, receive, top-up, transactions and virtual Visa routes.
- e-SIM, Crypto and Visa partner-dependent features remain clearly marked as unavailable/coming soon until backend/partner activation.
- Existing card purchase, physical-card delivery, admin, agency, designer and delivery routes remain mounted.
