# UI client attendue

En mobile, l'en-tête reste compact avec logo Market-Cash, cloche de notifications et menu. La navigation principale fixe en bas contient cinq entrées : **Accueil**, **Cartes**, **e-SIM**, **Crypto**, **Profil**.

L'ancien affichage principal limité à `Cartes / Aides / Profil` n'est plus l'interface cible. `Aide` reste accessible dans le menu supérieur.

La page Accueil expose le solde wallet et les raccourcis Envoyer, Recevoir, Recharger et Wallet. La page Cartes historique reste disponible afin de ne pas casser les demandes et livraisons déjà présentes.
