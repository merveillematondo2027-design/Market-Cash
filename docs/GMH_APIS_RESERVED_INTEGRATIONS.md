# Intégrations réservées à GMH APIs

| Fonction Market-Cash | Partenaire futur | Passage GMH APIs |
|---|---|---|
| Recharge Mobile Money | M-Pesa / opérateurs locaux | Oui |
| Paiement / règlement international | Banque / issuer | Oui |
| Visa virtuelle | Banque / issuer / processor autorisé | Oui |
| e-SIM | Fournisseur e-SIM autorisé | Oui |
| Crypto | Prestataire conforme et autorisé | Oui |
| Paiement QR/NFC interne Market-Cash | Réseau Market-Cash | Pas nécessaire si entièrement interne |

GMH APIs est l'orchestrateur commissionnaire des demandes partenaires ; il ne remplace pas le ledger Market-Cash ni les contrôles de conformité propres à Market-Cash.
